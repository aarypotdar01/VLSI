# VLSI

My learning journey in Very Large Scale Integration (VLSI) design.

This repository documents my progress from fundamental semiconductor
and CMOS concepts to digital design, HDL, verification, synthesis,
and physical design.

## Areas of Study

- CMOS & MOSFET Fundamentals
- Digital Circuit Design
- Verilog
- SystemVerilog
- Design Verification
- Logic Synthesis
- Static Timing Analysis
- Physical Design
- VLSI Projects

## Repository Structure

| Directory | Description |
|---|---|
| `CMOS/` | CMOS and transistor-level fundamentals |
| `Digital_Design/` | Digital logic and circuit design |
| `Verilog/` | Verilog HDL learning and implementations |
| `SystemVerilog/` | SystemVerilog concepts and coding |
| `Verification/` | Verification methodologies and testbenches |
| `Synthesis/` | Logic synthesis and related concepts |
| `Physical_Design/` | Physical design concepts and implementation |
| `Projects/` | Larger VLSI projects and experiments |

## Learning Approach

I am documenting concepts, experiments, simulations, and projects
as I progress through my VLSI learning journey.

The goal is to build a strong understanding of both front-end and
back-end VLSI before choosing a specialization.
